Where do my keys live?

Security key and passkey are everyday names. Here, a security key is a cross-platform authenticator whose credentials are single-device: bound to it, so only it can use the private key. A passkey is a discoverable credential on a platform authenticator or phone, usually multi-device: it can sync.

Security key
Stored: encrypted, as the credential ID, in your Chrome profile (synced). Usable: only inside that security key, which alone can decrypt it. Your keys: Cross-platform, Single-device.
Security key, stored on the key
Stored: in one of the security key's slots. Usable: only inside that security key. Import adds it on another computer; remove it with the security key's own tools (e.g. ykman fido credentials delete). Your keys: Cross-platform, Discoverable, Single-device.
Passkey
Stored: by the platform authenticator or phone, usually synced. Usable: by whoever can unlock it; a security key is stronger, as its keys are bound to it. Your keys: Platform (Cross-platform for a phone), Discoverable, usually backed up (✓).

Why verify synced keys? Whoever controls your Google account could swap a synced key's public key for their own. Verify checks it with the authenticator.

This key requires a PIN or fingerprint, but the certificate doesn't: servers will accept a touch alone. Ask for one with -O verify-required.
